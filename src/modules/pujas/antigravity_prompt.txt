1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
This repository hosts a zero-build, client-side, production-ready Single Page 
Application (SPA) designed for Hindu spiritual practitioners, families, and priests.
It provides complete, step-by-step guidance for 21 authentic Vedic rituals, 
classified systematically by Phase of Life (Shodasha Samskaras), major annual 
Vratams & Festivals, Astrological Dosha Pariharams, and Daily Observances.

Key capabilities:
- Full audio recitation (Priest Mode & Per-Step Chanting) via Web Speech API.
- Offline synthesized brass Temple Bell (Ghanta Dhwani) & Conch (Shankham) via Web Audio API.
- Bilingual instant switching (English <-> Telugu) across all UI strings, mantras, 
  checklists, and procedures without page reload.
- Interactive Samagri (Materials) Checklist with progress tracker and 1-click WhatsApp export.
- Dynamic Personalized Vedic Sankalpam Generator computing ongoing Samvatsara, Ayana, 
  Ritu, Masa, Paksha, Tithi, and Vasara for the user's Gotra, Nakshatra, and Name.
- Screen Wake Lock API to prevent phone/tablet screens from sleeping during rituals.
- Dual theme support (Dark Temple Night and Light Vedic Ashram Marble).
- Deployed directly on GitHub Pages using static branch hosting.

3. DATA SCHEMA & SPECIFICATION
--------------------------------------------------------------------------------
Each ritual in the database adheres to the following unified JavaScript Object schema:

{
  id: string,                      // Unique slug (e.g., 'seemantham', 'satyanarayana-vratam')
  category: string,                // 'life-phase' | 'vratam-festival' | 'pariharam' | 'daily'
  phase: string,                   // English phase (e.g., 'Pregnancy & Motherhood', 'Infancy & Childhood')
  phaseTe: string,                 // Telugu phase (e.g., 'గర్భధారణ & మాతృత్వ దశ')
  deity: string,                   // English presiding deity name
  deityTe: string,                 // Telugu presiding deity name
  title: {
    en: string,                    // English display title
    te: string                     // Telugu display title
  },
  subtitle: {
    en: string,                    // English brief description
    te: string                     // Telugu brief description
  },
  significance: {
    en: string,                    // Full spiritual, scriptural, and psychological significance
    te: string
  },
  bestTiming: {
    en: {
      season: string,              // Month / Season window
      tithi: string,               // Auspicious lunar tithi
      timeOfDay: string,           // Pratah, Madhyahna, Sandhya, Nishitha
      details: string              // Astrological notes, nakshatras, horai
    },
    te: {
      season: string,
      tithi: string,
      timeOfDay: string,
      details: string
    }
  },
  samagri: [                       // Array of required materials
    {
      nameEn: string,              // English item name
      nameTe: string,              // Telugu item name
      quantity: string,            // Exact measure/count
      optional: boolean,           // Whether item can be skipped if unavailable
      noteEn?: string,             // Purpose/usage notes
      noteTe?: string
    }
  ],
  steps: [                         // Sequential steps of the ritual
    {
      stepNumber: number,          // 1-based step counter
      title: { en: string, te: string },
      description: { en: string, te: string },
      mantra: {
        sanskrit: string,          // Devanagari or Telugu Sanskrit script
        transliteration: string,   // IAST / English phonetic pronunciation
        scriptTe: string           // Pure Telugu script rendering
      },
      meaning: { en: string, te: string }, // Theological & literal translation
      audioText: { en: string, te: string } // Text formatted for clean TTS speech
    }
  ]
}

4. SUBSYSTEM ARCHITECTURES
--------------------------------------------------------------------------------
A. AUDIO & ACOUSTIC ENGINE (js/audio-player.js)
   - Class: PujaAudioPlayer
   - Synthesizer (Web Audio API):
     * Temple Bell (playTempleBell()): Dual-oscillator bank with harmonics at 640Hz, 852Hz, 
       1280Hz, 1920Hz, 2560Hz. Exponential gain decay ramp simulating genuine bell bronze.
     * Sacred Conch (playConchSound()): 210Hz sawtooth wave sweeping to 260Hz then settling 
       to 245Hz, shaped by a 450Hz->750Hz->400Hz lowpass filter with slow attack.
   - Text-To-Speech (Web Speech API):
     * Matches best available voice: looks for 'te-IN' / 'te' for Telugu, or 'en-IN' (Indian English) 
       for English to ensure Sanskrit phonemes are pronounced authentically.
     * Speed Rate: Selectable 0.75x (meditative), 0.9x (optimal/default), 1.0x, 1.2x.
     * Queue Management: priest mode walks sequentially through intro, steps, mantras, and meanings, 
       emitting callbacks to highlight the active step on screen and scrolling into view.

B. PANCHANGA & SANKALPAM ENGINE (js/sankalpam.js & js/data/panchang-data.js)
   - Object: Sankalpam
   - getCalendarElements(date):
     * Computes Samvatsara from Jovian 60-year cycle: (year - 4 + 60) % 60.
     * Identifies Uttarayana (Jan-June) vs. Dakshinayana (July-Dec).
     * Derives Ritu: Vasanta, Greeshma, Varsha, Sharad, Hemanta, Shishira.
     * Approximates lunar Masa, Paksha (Shukla/Krishna), Tithi (1-15), and Vasara (Day).
   - generate(userProfile, pujaName, lang):
     * Injects Gotram, Nakshatram, Devotee Name, and Spouse Name into classical Vedic formula.
     * Outputs: sanskritText, transliteration, meaningTe, meaningEn.

C. CLIENT PERSISTENCE (js/storage.js)
   - Object: Storage
   - LocalStorage Keys:
     * 'pujas_settings'          : { language: 'en', theme: 'dark', speechRate: 0.9, soundEffects: true }
     * 'pujas_bookmarks'         : Array<string> of bookmarked puja IDs
     * 'pujas_checklists'        : Object mapping pujaId -> Array<number> of checked item indices
     * 'pujas_sankalpam_profile' : { gotra, nakshatra, name, spouseName, city }

D. UI ORCHESTRATION & DOM CONTROLLER (js/app.js)
   - All DOM query selectors are declared at the very top of DOMContentLoaded to eliminate 
     JavaScript Temporal Dead Zone (TDZ) ReferenceErrors.
   - Defensive checks (if (element)) exist on all event listeners and UI updates.
   - Live Search: Instant real-time search filtering across both English and Telugu titles, 
     subtitles, and deities simultaneously.
   - WhatsApp Exporter: Formats checklist into WhatsApp markdown and opens wa.me deep-link.
   - Screen Wake Lock: Requests 'screen' lock via navigator.wakeLock with fallback alert.

7. CRITICAL ARCHITECTURAL RULES & GOTCHAS
--------------------------------------------------------------------------------
1. GITHUB PAGES DEPLOYMENT:
   - This repository is configured to deploy via the static branch method:
     Branch: 'main', Folder: '/' (root)
   - DO NOT create a '.github/workflows/deploy.yml' file unless the repository settings 
     at https://github.com/sv007git/Pujas/settings/pages have explicitly been changed from 
     'Deploy from a branch' to 'GitHub Actions'. Pushing a workflow while in 'branch' mode 
     triggers an unnecessary 404 Action failure.
   - A mirror branch 'gh-pages' is also maintained:
     git push origin main
     git push origin main:gh-pages

2. JAVASCRIPT SCOPING:
   - All shared data arrays and helper classes must be defensively assigned to both 
     window and globalThis (e.g., if (typeof window !== 'undefined') window.X = X;).
   - In app.js, never access DOM elements or call functions that reference DOM element 
     variables before their const declarations.

3. DEFAULT LANGUAGE:
   - The default language MUST always remain English ('en').
   - When the user clicks the language toggle ('🌐 తెలుగు'), the entire application shifts 
     to Telugu. Clicking '🌐 English' switches back.

4. STATIC PATH RESILIENCY:
   - All asset references (CSS, JS, icons) in index.html and 404.html MUST use relative 
     paths (e.g., 'css/style.css', 'js/app.js') rather than absolute root slashes ('/css/style.css')
     so that the app functions seamlessly whether hosted at root or under a subpath like /Pujas/.
