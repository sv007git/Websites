An interactive, high-contrast **monochrome Black & White** medical application hosted directly on GitHub Pages. Explore interactive vector illustrations of **Baby**, **Man**, and **Woman** across both **Internal Organs** and **External Surface Anatomy**. Clicking or hovering over any body part instantly reveals the **Top 10 diseases** related to that part, accompanied by an in-depth **holistic protocol** and crystal-clear **English voice narration**.

## 🌟 Key Features

### 1. 🩻 Interactive Vector Anatomy Engine
- **3 Demographics**:
  - 👨 **Man**: Adult male anatomical framework.
  - 👩 **Woman**: Adult female anatomy including reproductive biology and breast health.
  - 👶 **Baby**: Pediatric / infant proportions, fontanelles, colic/navel, and rapid development markers.
- **2 Deep Layers**:
  - 🩻 **Internals**: Brain, Heart, Lungs, Liver, Stomach, Kidneys, Pancreas, Intestines, Spine, Male Reproductive, Female Reproductive, and Infant Internal Viscera.
  - 👤 **Externals**: Head & Scalp, Eyes, Ears, Nose & Sinuses, Mouth & Throat, Neck & Thyroid, Chest & Breasts, Abdomen & Core, Hands & Wrists, Hips & Pelvis, Knees & Legs, Feet & Ankles, and Integumentary Skin.
- **Micro-Interactions**: Hover highlights, pulsating organ outlines, dynamic cursor tooltips, pan & zoom controls (75% to 250%), and keyboard shortcuts.

### 2. 📋 Top 10 Diseases per Body Part (250 Full Protocols)
Clicking any organ dynamically presents the **Top 10 most critical, prevalent, and clinically significant conditions** (25 anatomical regions × 10 conditions = **250 comprehensive clinical profiles**).

Each condition contains an 8-pillar integrated protocol:
1. **🔍 Root Causes & Pathophysiology**: Cellular, bacterial, viral, metabolic, genetic, or environmental etiologies.
2. **🛡️ Primary Prevention**: Actionable screening guidelines, hygienic measures, and risk-reduction strategies.
3. **🌿 Lifestyle & Diet**: Circadian rhythms, nutritional adjustments, hydration, sleep optimization, and stress reduction.
4. **💊 Modern Allopathic Therapeutics**: First-line pharmacological interventions, classes, and medical guidelines.
5. **🫖 Classical Ayurveda**: Dosha imbalances (Vata, Pitta, Kapha), single herbs, classical polyherbal formulations, and panchakarma therapies.
6. **🖐️ Therapeutic Mudras**: Specific hand gestures with finger placement, hold durations, and bio-energetic benefits.
7. **🧘 Yoga & Pranayama**: Restorative asanas, therapeutic breathwork sequences, and clinical cautions.
8. **🧪 Vitamin & Mineral Deficiencies**: Micronutrient gaps (Vitamins D3, B12, C, Iron, Magnesium, Zinc) and targeted bioavailable whole foods.
9. **☀️ Integrated Daily Regimen**: A cohesive dawn-to-dusk routine bridging modern medicine and natural therapies.

### 3. 🔊 English Voice Narration Engine
- **Web Speech Synthesis**: Automatically selects natural, human-like English voices (e.g., Google US English, Samantha, Microsoft Natural).
- **Acoustic Audio Chimes**: Web Audio API sine-wave chimes providing immediate tactile audio feedback on organ and disease selection.
- **Live Waveform Visualizer**: Synchronous monochrome CSS animated soundwave indicating active narration.
- **Narration Speed Controls**: Toggle speech rate between `0.8x` (Gentle), `1.0x` (Standard), `1.15x` (Brisk), and `1.3x` (Fast).
- **Auto-Narration Mode**: Optional toggle that automatically narrates any organ or disease when clicked.

### 4. 🖤 Pure Black & White Monochrome Design
- High-contrast, accessibility-focused monochrome palette.
- **Dark Mode (Default)**: Deep black `#000000` backdrop with crisp white vector lines.
- **Light Mode**: Clean clinical paper-white `#ffffff` aesthetic toggled with one click or the `T` key.
- **Print & PDF Export**: Dedicated `@media print` stylesheet allowing users to export or print any holistic disease protocol cleanly without UI clutter.

## 💻 Tech Stack & Architecture

- **Zero External Dependencies**: Pure Vanilla ES6+, CSS3 Modern Variables, and HTML5.
- **Fast & Lightweight**: Sub-second load times on any browser or mobile device.
- **GitHub Pages Native**: Zero build step required. Direct serving from root repository.
- **Audio**: Web Speech Synthesis API + Web Audio API oscillator for haptic soundscapes.
- **Vector Graphics**: Pure programmatic inline SVG with SVG viewBox scaling.

```
Doctor/
├── .nojekyll                 # Ensures GitHub Pages serves all assets directly
├── index.html                # Main semantic application dashboard
├── README.md                 # Complete documentation and clinical catalog
├── css/
│   └── styles.css            # Black & White monochrome design system (957 lines)
├── js/
│   ├── data.js               # 25 body parts & 250 fully structured holistic conditions
│   ├── audio.js              # English speech synthesis & acoustic chime engine
│   ├── anatomy-svg.js        # Vector anatomy renderer with pan/zoom and hotspots
│   └── app.js                # Main application state orchestrator & search
└── assets/
    └── favicon.svg           # High-contrast medical cross and holistic circle icon
```

## 🚀 How to Run Locally

Since this project has zero external dependencies, you can run it instantly using any static web server:

### Option 1: Python 3
```bash
cd Doctor
python -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

### Option 2: Node.js `npx serve`
```bash
cd Doctor
npx serve .
```

### Option 3: Direct File Opening
Double-click `index.html` to open it in Google Chrome, Microsoft Edge, Safari, or Firefox.

## 🚢 Deploying to GitHub Pages (`https://github.com/sv007git/Doctor`)

To push this repository to your GitHub account:

```bash
# 1. Initialize git (if not already done)
git init

# 2. Add remote repository
git remote add origin https://github.com/sv007git/Doctor.git

# 3. Stage and commit all files
git add .
git commit -m "Initial commit: Complete holistic anatomy & disease intelligence system"

# 4. Push to GitHub main branch
git branch -M main
git push -u origin main
```

### Enabling GitHub Pages:
1. Go to your repository on GitHub: `https://github.com/sv007git/Doctor/settings/pages`
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and root `/ (root)`.
4. Click **Save**.
5. Your live site will be deployed at: **`https://sv007git.github.io/Doctor/`**
