1. PROJECT PURPOSE & CORE FUNCTIONALITY
--------------------------------------------------------------------------------
"Doctor" is an interactive, accessibility-focused, pure black-and-white monochrome
medical exploration dashboard. It bridges modern clinical medicine (Allopathy) with
classical holistic healing sciences (Ayurveda, Mudras, Yoga & Pranayama, Micronutrient
Dietary Deficiencies, and Circadian Lifestyle Protocols).

Core capabilities:
1. Interactive Vector Anatomy Visualizer:
   - 3 Demographics: Adult Male (Man), Adult Female (Woman), Pediatric Infant (Baby).
   - 2 Anatomical Layers:
     * Internals (visceral organs: Brain, Heart, Lungs, Liver, Stomach, Kidneys, Pancreas, Intestines, Spine, Reproductive Systems).
     * Externals (sensory & musculoskeletal: Head/Scalp, Eyes, Ears, Nose, Mouth/Throat, Neck/Thyroid, Chest/Breasts, Core, Hands, Hips, Legs, Feet, Skin).
   - Dynamic vector SVG with hover outlines, active pulsating glows, zoom/pan controls, and floating tooltips.
2. Top 10 Diseases per Body Part:
   - Exactly 25 anatomical parts × 10 diseases = 250 fully clinically researched conditions.
   - Each condition features an 8-pillar holistic protocol:
     * Root causes & pathophysiology
     * Primary prevention strategies
     * Lifestyle habits & circadian diet
     * Modern allopathic pharmacology & treatments
     * Classical Ayurveda (doshas, single herbs, polyherbal formulations, therapies)
     * Therapeutic hand mudras (exact finger technique, duration, benefits)
     * Yoga asanas & pranayama breathwork
     * Vitamin/mineral deficiencies & bioavailable whole food sources
     * Integrated daily morning-to-night routine
3. English Voice Narration Engine:
   - Web Speech API synthesis prioritizing natural English voices (Google, Microsoft, Apple).
   - Web Audio API dual-oscillator acoustic chimes on organ & disease selection.
   - Live CSS waveform animation bar.
   - Narration speed controls (0.8x, 1.0x, 1.15x, 1.3x) and auto-speech mode on click.
4. Pure Black & White Monochrome Design System:
   - Ultra high-contrast palette (#000000 dark mode default, #ffffff paper light mode).
   - Keyboard shortcuts: 'T' for theme, 'Space' for audio toggle, 'Esc' to clear search/modals.
   - Dedicated print stylesheet for clean 1-page PDF/paper protocol exports.

3. ARCHITECTURAL CONTRACTS & SCRIPT DEPENDENCIES
--------------------------------------------------------------------------------
The scripts in index.html are loaded synchronously in the following order:
1. js/data.js         -> Declares global `const ANATOMY_DATA = { demographics, layers, parts }`
2. js/audio.js        -> Declares class `HolisticAudioEngine`, instantiates `window.AudioEngine`
3. js/anatomy-svg.js  -> Declares class `AnatomySVGViewer`
4. js/app.js          -> Declares class `HolisticApp`, instantiates `window.App` on DOMContentLoaded

There are NO package managers, NO npm builds, NO bundlers, and NO third-party CDNs.
Everything runs natively in all modern browsers (Chrome, Edge, Firefox, Safari).

5. ANATOMY VECTOR SVG ENGINE (js/anatomy-svg.js)
--------------------------------------------------------------------------------
Class: `AnatomySVGViewer(containerId)`
- Container: `#anatomy-canvas-container`
- ViewBox: `0 0 500 800`
- Zoom level: Min `0.75`, Max `2.5`, Default `1.0` (with `#zoom-level-display`)
- Interactive element: `<g class="anatomy-hotspot" data-part-id="...">`
- Event callbacks:
  * `onPartSelect(partId)`: Fired on click or Enter key.
  * `onPartHover(partId, mouseEvent, boundingClientRect)`: Fired on mouseenter/mousemove/mouseleave.
- SVG Layers:
  * `getInternalSVG()`: Generates anatomical vector shapes for man/woman/baby internal organs.
  * `getExternalSVG()`: Generates anatomical vector shapes for surface body regions.
- SVG styling:
  * `.organ-fill`: semi-transparent monochrome fill with glowing stroke.
  * `.anatomy-hotspot:hover .organ-fill`: increased stroke width + drop-shadow.
  * `.anatomy-hotspot.is-active .organ-fill`: prominent monochrome highlight + filter glow.

6. AUDIO SPEECH & ACOUSTIC SYNTHESIZER (js/audio.js)
--------------------------------------------------------------------------------
Class: `HolisticAudioEngine`
Global instance: `window.AudioEngine`
- TTS Engine: Window `speechSynthesis` API
  * Voice filter: Selects best available English voice (`en-US`, `en-GB`, etc.).
  * Speech rate: Supported speeds `0.8`, `1.0`, `1.15`, `1.3`.
  * Auto-Speech toggle: `autoSpeak` boolean (reads overview or disease protocol on click).
  * State hook: `onStateChange({ isPlaying, isPaused, text })`.
- Sound Effects: Window `AudioContext` / `webkitAudioContext`
  * Dual-sine wave oscillators generating clean, ambient acoustic chimes without audio files.
  * Chime types: "select" (880Hz -> 1320Hz), "organ" (440Hz -> 660Hz), "disease" (523.25Hz -> 783.99Hz), "error".
- Script Generators:
  * `generatePartScript(part, demographicLabel)`: Concise ~30 second spoken organ summary.
  * `generateDiseaseScript(disease)`: Structured spoken clinical and holistic overview covering cause, prevention, allopathy, ayurveda, mudra, yoga, and vitamins.

7. APPLICATION CONTROLLER & UI EVENT BUS (js/app.js)
--------------------------------------------------------------------------------
Class: `HolisticApp`
Global instance: `window.App`

Key State Properties:
- `demographic`: "man" | "woman" | "baby"
- `layer`: "internals" | "externals"
- `selectedPartId`: Current active anatomical part ID (defaults to "brain")
- `selectedDiseaseId`: Current selected disease ID (or null)
- `searchQuery`: Current search string
- `theme`: "dark" | "light" (stored in localStorage: `doctor_theme`)

DOM Element ID Map:
- Header & Global Controls:
  * `[data-demographic]`: Switcher buttons for Man, Woman, Baby
  * `[data-layer]`: Switcher buttons for Internals, Externals
  * `#theme-toggle-btn`: Theme switcher button (Dark/Light)
- Left Anatomy Panel:
  * `#anatomy-canvas-container`: Host for the SVG canvas
  * `#zoom-in-btn`, `#zoom-out-btn`, `#zoom-reset-btn`: SVG zoom toolbar
  * `#zoom-level-display`: Displays zoom percentage (e.g. "100%")
  * `#anatomy-tooltip`: Floating cursor tooltip
- Right Content Panel:
  * `#disease-search-input`: Real-time fuzzy search input across diseases, herbs, mudras, vitamins
  * `#search-clear-btn`: Clear search button
  * `#part-overview-card`: Active anatomical part summary card
  * `#diseases-count-badge`: Displays count (e.g. "10 Conditions")
  * `#top-diseases-grid`: Container rendering the 10 disease cards
  * `#holistic-protocol-container`: Container rendering the deep-dive 8-column protocol
- Bottom Audio Bar:
  * `#audio-visualizer`: Waveform bar container (.is-playing animates 6 bars)
  * `#audio-now-playing-title`: Text label for currently narrating topic
  * `#global-audio-play-btn`: Play/Pause/Resume narration button
  * `#global-audio-stop-btn`: Stop narration button
  * `#auto-speak-toggle-btn`: Toggle auto-speech on selection
  * `#audio-rate-select`: Speed dropdown (0.8x, 1.0x, 1.15x, 1.3x)

Keyboard Shortcuts:
- `T` or `t`: Toggle Black/White theme.
- `Space`: Pause / Resume audio narration (when not typing in an input).
- `Esc`: Close deep-dive protocol modal or clear search.
