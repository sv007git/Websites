1. EXECUTIVE SUMMARY & PURPOSE
--------------------------------------------------------------------------------
This platform makes the entire CBSE / NCERT English Medium curriculum from
Class 1 to 12 intuitive, joyful, and memorable by converting academic textbook
chapters into character-driven cartoon comic strips, hands-on interactive labs,
spoken English audio narrations, and checkpoint quizzes.

Key Tenets:
1. Pure Black & White Comic Strip Aesthetic:
   - High contrast (#000000 on #ffffff) with comic printing halftone dots.
   - Neobrutalist 3D ink shadows (4px 4px 0px #000), bold panel borders.
   - Expressive speech bubbles with directional pointers.
   - Inverted Noir Manga Mode toggle for nighttime reading.
   - Scalable inline vector (SVG) artwork that prints crisply on any printer.
2. English Voice Speech Narration:
   - Built-in Web Speech API Text-to-Speech (TTS) reading panels in English.
   - Distinct character pitch/speed profiles (Prof. Paws, Pixel Bot, Sparky, etc.).
   - Sequential "Read Entire Comic Aloud" mode with active panel tracking.
   - 100% procedural Web Audio API cartoon sound effects (boing, pop, fanfare,
     buzzer, page flip) with zero external MP3 assets.
3. Class 1 to 12 NCERT Scope:
   - Categorized into 5 stages: Foundational (1-2), Preparatory (3-5),
     Middle School (6-8), Secondary (9-10), Senior Secondary (11-12).
   - Covers Mathematics, Science (Physics/Chemistry/Biology), Social Science,
     and English.
4. Tactile Mini-Labs:
   - Interactive, formula-driven simulators (e.g., F = ma cart, Ohm's law,
     Photosynthesis engine, Pizza fraction slicer).
5. Parent-Child Bonding:
   - Parent Learning Hub with dinner-table conversation prompts.
   - Progress and badge tracking saved in browser localStorage.
   - Printable Black & White Cartoon Certificate of Achievement.

--------------------------------------------------------------------------------
A. AUDIO NARRATOR ENGINE (`js/audio-narrator.js`)
--------------------------------------------------------------------------------
Global instance: `window.audioNarrator`
Class: `AudioNarrator`

State & Properties:
- `synth`: `window.speechSynthesis`
- `audioCtx`: `AudioContext` (initialized/resumed on user gesture)
- `voices`: Filtered list of English voices (`en-US`, `en-GB`, `en-IN`, etc.)
- `selectedVoice`: Active SpeechSynthesisVoice object
- `rate`: Speech speed multiplier (default: 1.0, range: 0.6 to 1.6)
- `pitch`: Pitch multiplier (default: 1.0)
- `isMuted`: Boolean flag controlling both speech and sound FX

Character Voice Profiles (`characterProfiles`):
- `narrator`:   { pitch: 1.00, rate: 0.95, prefix: "" }
- `prof-paws`:  { pitch: 0.85, rate: 0.92, prefix: "Professor Paws says: " }
- `pixel-bot`:  { pitch: 1.35, rate: 1.05, prefix: "Pixel says: " }
- `luna-owl`:   { pitch: 0.95, rate: 0.88, prefix: "Luna explains: " }
- `sparky`:     { pitch: 1.40, rate: 1.10, prefix: "Sparky exclaims: " }
- `doodler`:    { pitch: 1.10, rate: 1.00, prefix: "Doodler notes: " }

Primary Methods:
- `speak(text, options = { character, onStart, onEnd, onError })`:
  Stops current utterance, cleans tags, applies character profile, speaks English.
- `stop()`: Halts speech synthesis and cancels auto-read timer.
- `pause()`, `resume()`, `toggleMute()`.
- `setVoice(voiceURI)`, `setSpeed(speedVal)`, `getEnglishVoices()`.
- `startComicAutoNarrate(panels, onPanelStart(index, item), onFinish())`:
  Sequentially plays through panels, triggers highlights, pauses 900ms between panels.

Procedural Web Audio SFX Methods (Zero external MP3 dependencies!):
- `playPop()`: 350Hz -> 800Hz sine burst (0.08s) for UI taps.
- `playBoing()`: 220Hz -> 540Hz -> 320Hz sine with tremolo (0.35s) for comic springs.
- `playSuccess()`: 4-note arpeggio (C5, E5, G5, C6) with triangle waves for rewards.
- `playBuzzer()`: 140Hz -> 95Hz sawtooth drop (0.25s) for quiz errors.
- `playPageFlip()`: Filtered white-noise burst (1200Hz bandpass, 0.06s) for comic rustle.
- `playClick()`: Subtle tick for buttons.

D. INTERACTIVE MINI-LABS (`js/interactive-labs.js`)
--------------------------------------------------------------------------------
Global instance: `window.interactiveLabs`
Class: `InteractiveLabs`

Method: `renderLab(labId, mountElement)`
Renders tactile, black-and-white, SVG/HTML5 interactive simulators into any container.

Available Mini-Labs:
1. `shape-sorter` (Class 1-2):
   - Click shapes (Circle, Square, Triangle) and test fitting them into garage slots.
   - Dynamic feedback with sound effects (Success chime vs Buzzer boing).
2. `photosynthesis-lab` (Class 3-7):
   - Sliders for Sunlight Intensity, Water from Roots, and CO2 in air.
   - Demonstrates Blackman's law of limiting factors: Glucose & O2 meters clamp
     to the lowest ingredient.
3. `pizza-fraction-lab` (Class 3-5):
   - Interactive SVG pizza divided into 2, 4, 6, or 8 slices.
   - Click slices to eat them; updates live fraction (a/b), remaining slices,
     percentage, and equivalent fractions (4/8 = 1/2).
4. `circuit-builder` (Class 6-8):
   - Toggle knife switch ON/OFF; adjust battery voltage (1.5V to 9.0V).
   - Test materials: Conductors (Copper wire, Iron nail) vs Insulators (Rubber,
     Wood, Plastic). Bulb filaments glow with animated electron flow lines.
5. `newtons-cart` (Class 9-11):
   - Physics cart simulator testing F = ma.
   - Select mass (1kg, 2kg, 5kg, 10kg), set push force slider (5N to 50N).
   - Hit "LAUNCH CART!" to trigger physics animation with duration proportional
     to calculated acceleration a = F/m.
6. `ohms-law-lab` (Class 10-12):
   - Ohm's law triangle (V = I * R).
   - Manipulate Voltage (1V-24V) and Resistance (1Ω-24Ω) to watch Ampere meter
     and flow intensity calculate in real time.

5. HOW TO EXTEND THE PROJECT (RECIPES FOR FUTURE AGENTS)
================================================================================

RECIPE 1: HOW TO ADD A NEW CHAPTER TO A SUBJECT
--------------------------------------------------------------------------------
1. Open `js/ncert-curriculum.js`.
2. Locate the desired class in `NCERT_DATA.classes[classNumber]`.
3. Locate the subject in `subjects` array (e.g., `c7-sci`).
4. Append a new chapter object to `chapters`:
   ```javascript
   {
     id: "c7-s4",
     title: "Motion and Time: The Oscillating Simple Pendulum",
     comicId: "c7-sci-pendulum",
     concept: "Periodic motion, time period of simple pendulum T = 2π√(L/g)",
     cartoonHook: "Pixel the robot builds a grandfather clock with a swinging cat toy!"
   }
   ```

RECIPE 2: HOW TO ADD A NEW CARTOON COMIC STRIP
--------------------------------------------------------------------------------
1. Open `js/comic-stories.js`.
2. Add a new story key matching the `comicId` above:
   ```javascript
   "c7-sci-pendulum": {
     id: "c7-sci-pendulum",
     classNum: 7,
     subjectId: "c7-sci",
     title: "Motion and Time: The Swinging Comic Pendulum!",
     subtitle: "Back and forth with constant rhythm: The secret of clocks!",
     concept: "A simple pendulum executes periodic motion. Time period depends on string length.",
     characters: ["prof-paws", "pixel-bot"],
     interactiveLabId: null, // or add a lab ID
     panels: [
       {
         panelNum: 1,
         speaker: "Pixel Bot",
         characterKey: "pixel-bot",
         soundEffect: "TICK-TOCK!",
         narration: "In the antique clock shop...",
         dialogue: "Professor! Why does this swinging bob take the exact same time on every swing?",
         svgArt: `<svg viewBox="0 0 400 240" class="comic-svg">
           <rect x="20" y="20" width="360" height="200" fill="#fff" stroke="#000" stroke-width="4"/>
           <line x1="200" y1="40" x2="160" y2="160" stroke="#000" stroke-width="3"/>
           <circle cx="160" cy="160" r="16" fill="#000"/>
           <text x="200" y="210" text-anchor="middle" font-weight="bold" font-size="14">PERIODIC MOTION</text>
         </svg>`
       },
       // Add panels 2, 3, 4...
     ],
     takeaway: "NCERT Takeaway: The time taken by a pendulum to complete one oscillation is its time period.",
     quiz: [
       {
         question: "What happens to the time period of a pendulum if you make the string longer?",
         options: ["Time period increases (swings slower)", "Time period decreases", "It stops swinging", "It spins in a circle"],
         correctIndex: 0,
         explanation: "A longer string has a greater time period, so it swings more slowly!"
       }
     ]
   }
   ```

RECIPE 3: HOW TO ADD A NEW INTERACTIVE MINI-LAB
--------------------------------------------------------------------------------
1. Open `js/interactive-labs.js`.
2. In `renderLab(labId, mountElement)`, add a new case to the switch:
   ```javascript
   case "pendulum-lab":
     this.renderPendulumLab();
     break;
   ```
3. Implement `renderPendulumLab()` with DOM controls, SVG visualizer, sound FX,
   and narration feedback.
4. Add the lab metadata into the gallery list in `js/app.js` (`renderLabsGallery`).
